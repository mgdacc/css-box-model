Cheat Sheet de CSS

Box Model
1 / 16

"Todo es una Caja"

No importa si es un círculo, un texto o una imagen. Para el navegador, todo elemento HTML es un rectángulo compuesto por capas.

/* Las 4 capas del modelo de caja: */

1. Content (El contenido real: texto, img)
2. Padding (Relleno interior)
3. Border  (El borde o límite)
4. Margin  (Espacio exterior)
2 / 16

1. Width & Height

Definen el tamaño del área de contenido (content area). Por defecto, no incluyen ni el borde ni el padding.

.caja {
  width: 200px;
  height: 100px;
  background-color: lightblue;
}

/* Si agregas padding, la caja visual 
   crecerá más allá de estos 200px. */
3 / 16

2. Padding (Relleno)

Es el espacio transparente entre el contenido y el borde. Toma el color de fondo del elemento.

div {
  /* Un valor: aplica a los 4 lados */
  padding: 20px;

  /* Shorthand: Arriba | Derecha | Abajo | Izquierda */
  /* Regla del reloj CLOCKWISE */
  padding: 10px 20px 15px 5px;
}
4 / 16

3. Border (Borde)

Rodea el padding y el contenido. Requiere definir grosor, estilo y color.

.tarjeta {
  /* width | style | color */
  border: 2px solid #4fc3f7;
  
  /* Bordes individuales */
  border-bottom: 5px dashed red;
  
  /* Redondear esquinas (afecta visualmente al borde) */
  border-radius: 10px;
}
5 / 16

4. Margin (Margen)

Es el espacio fuera del borde. Separa el elemento de sus vecinos. Es completamente invisible.

h1 {
  /* Arriba y Abajo | Izquierda y Derecha */
  margin: 20px 0;
}

.centro {
  width: 50%;
  /* Truco clásico para centrar horizontalmente */
  margin: 0 auto;
}
6 / 16

El Problema del Tamaño Real

Por defecto, si defines width: 100px y agregas padding: 20px, ¡la caja medirá 140px!

/* box-sizing: content-box (Valor por defecto) */

.caja-problematica {
  width: 100px;
  padding: 20px; 
  border: 5px solid black;
}

/* Ancho Total = 100 + 20+20 + 5+5 = 150px */
7 / 16

La Solución: Box Sizing

border-box cambia el cálculo para que el padding y el borde queden dentro del ancho definido.

/* Reset CSS Recomendado */
* {
  box-sizing: border-box;
}

.caja-logica {
  width: 100px;
  padding: 20px;
  /* El ancho total en pantalla SERÁ 100px.
     El contenido se encoge automáticamente. */
}
8 / 16

Propiedad Outline

Dibuja una línea fuera del borde. A diferencia del borde, no ocupa espacio y puede superponerse a otros elementos.

button:focus {
  /* Muy importante para accesibilidad (teclado) */
  outline: 3px solid orange;
  
  /* Separación entre el borde y el outline */
  outline-offset: 5px;
}
9 / 16

Box Shadow (Sombra)

Añade efectos de sombra a la caja. Sintaxis: X, Y, Blur, Spread, Color.

.boton {
  /* Offset-X | Offset-Y | Blur | Color */
  box-shadow: 5px 5px 10px rgba(0,0,0,0.5);
}

/* El Spread (4to valor) es opcional y expande la sombra */
box-shadow: 0 0 10px 5px red;
10 / 16

Box Shadow: Inset

La palabra clave inset cambia la sombra para que sea interior, creando un efecto de profundidad "hundido".

.input-texto {
  background-color: #eee;
  
  /* Sombra interna */
  box-shadow: inset 0 2px 5px rgba(0,0,0,0.2);
}
11 / 16

Colapso de Márgenes (Gotcha!)

Cuando dos márgenes verticales se tocan, no se suman. Se combinan y prevalece el mayor.

h1 { margin-bottom: 30px; }
p  { margin-top: 20px; }

/* El espacio real entre h1 y p NO será 50px.
   Será 30px (el mayor de los dos). */

/* Nota: Esto no pasa con márgenes horizontales. */
12 / 16

Display y el Modelo de Caja

El comportamiento de la caja depende de su display.

span {
  display: inline;
  /* Ignora width, height y márgenes verticales. */
}

div {
  display: block;
  /* Ocupa todo el ancho disponible. Respeta todo. */
}

img {
  display: inline-block;
  /* En línea, pero respeta width/height/margins. */
}

Debugueando Cajas

Un truco clásico para ver dónde están tus cajas si el diseño se rompe.

* {
  border: 1px solid red; 
  /* O usa outline para no afectar el tamaño */
  outline: 1px solid lime;
}

/* Consejo Pro: Usa el Inspector de Elementos 
   del navegador (F12). */
14 / 16

Ejemplo Completo

Combinando todas las propiedades para una tarjeta de perfil.

.card {
  width: 300px;
  padding: 20px;
  margin: 0 auto;
  border: 1px solid #ddd;
  box-shadow: 0 4px 8px rgba(0,0,0,0.1);
  box-sizing: border-box;
}
15 / 16

Resumen

El Modelo de Caja es la ley en CSS.

1. Usa siempre 'box-sizing: border-box'.
2. Recuerda: Content -> Padding -> Border -> Margin.
3. Margin crea distancia entre elementos.
4. Padding crea aire dentro del elemento.
5. Outline no afecta el layout (bueno para focus).
6. Cuidado con el colapso de márgenes verticales.
